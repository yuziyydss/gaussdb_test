1.6.12 文本检索函数和操作符
文本检索操作符
      ●   @@
          描述：tsvector类型的词汇与tsquery类型的词汇是否匹配。
          示例：
          gaussdb=# SELECT to_tsvector('fat cats ate rats') @@ to_tsquery('cat & rat') AS RESULT;
           result
          --------
           t
          (1 row)

      ●   @@@
          描述：@@的同义词。
          示例：
          gaussdb=# SELECT to_tsvector('fat cats ate rats') @@@ to_tsquery('cat & rat') AS RESULT;
           result
          --------
           t
          (1 row)

      ●   ||
          描述：连接两个tsvector类型的词汇。
          示例：
          gaussdb=# SELECT 'a:1 b:2'::tsvector || 'c:1 d:2 b:3'::tsvector AS RESULT;
                   result
          ---------------------------
           'a':1 'b':2,5 'c':3 'd':4
          (1 row)

      ●   &&
          描述：将两个tsquery类型的词汇进行“与”操作。
          示例：
          gaussdb=# SELECT 'fat | rat'::tsquery && 'cat'::tsquery AS RESULT;
                   result
          ---------------------------
           ( 'fat' | 'rat' ) & 'cat'
          (1 row)

      ●   ||
          描述：将两个tsquery类型的词汇进行“或”操作。
          示例：
[[PDF_PAGE physical=398 printed=349]]
             gaussdb=# SELECT 'fat | rat'::tsquery || 'cat'::tsquery AS RESULT;
                     result
             -----------------------
              'fat' | 'rat' | 'cat'
             (1 row)

         ●   !!
             描述：tsquery类型词汇的非关系。
             示例：
             gaussdb=# SELECT !! 'cat'::tsquery AS RESULT;
              result
             --------
              !'cat'
             (1 row)

         ●   <->
             描述：将两个tsquery类型的词汇进行“词组”操作。
             示例：
             gaussdb=# SELECT 'fat'::tsquery <-> 'cat'::tsquery AS RESULT;
                 result
             -----------------
              'fat' <-> 'cat'
             (1 row)

         ●   @>
             描述：一个tsquery类型的词汇是否包含另一个tsquery类型的词汇。
             示例：
             gaussdb=# SELECT 'cat'::tsquery @> 'cat & rat'::tsquery AS RESULT;
              result
             --------
              f
             (1 row)

         ●   <@
             描述：一个tsquery类型的词汇是否被包含另一个tsquery类型的词汇。
             示例：
             gaussdb=# SELECT 'cat'::tsquery <@ 'cat & rat'::tsquery AS RESULT;
              result
             --------
              t
             (1 row)

         除了上述的操作符，还为tsvector类型和tsquery类型的数据定义了普通的B-tree比较操
         作符（=，<等）。

文本检索函数
         ●   get_current_ts_config()
             描述：获取文本检索的默认配置。
             返回类型：regconfig
             示例：
             gaussdb=# SELECT get_current_ts_config();
              get_current_ts_config
             -----------------------
              english
             (1 row)

         ●   length(tsvector)
             描述：tsvector类型词汇的单词数。
[[PDF_PAGE physical=399 printed=350]]
    返回类型：integer
    示例：
    gaussdb=# SELECT length('fat:2,4 cat:3 rat:5A'::tsvector);
     length
    --------
         3
    (1 row)

●   numnode(tsquery)
    描述：tsquery类型的单词加上操作符的数量。
    返回类型：integer
    示例：
    gaussdb=# SELECT numnode('(fat & rat) | cat'::tsquery);
     numnode
    ---------
          5
    (1 row)

●   plainto_tsquery([ config regconfig, ] query text)
    描述：产生tsquery类型的词汇，使用&（AND）作为连接操作符，并忽略标点。
    返回类型：tsquery
    示例：
    gaussdb=# SELECT plainto_tsquery('english', 'The Fat Rats');
     plainto_tsquery
    -----------------
     'fat' & 'rat'
    (1 row)

●   phraseto_tsquery([ config regconfig, ] query text)
    描述：产生tsquery类型的词汇，使用<->（PHRASE）作为连接操作符，并忽略标
    点。config为token配置词典，详情请参见词典。
    返回类型：tsquery
    示例：
    gaussdb=# SELECT phraseto_tsquery('english', 'The Fat Rats');
     phraseto_tsquery
    ------------------
     'fat' <-> 'rat'
    (1 row)

●   tsquery_phrase(query1 tsquery, query2 tsquery [, distance regdistance])
    描述：使用词组操作符（PHRASE）连接tsquery类型。query1和query2可使用
    text类型数据，会尝试转换为tsquery类型。distance可指定query1和query2的距
    离。
    返回类型：tsquery
    示例：
    --不指定距离，默认为1。
    gaussdb=# SELECT tsquery_phrase(to_tsquery('fat'), to_tsquery('cat'));
     tsquery_phrase
    -----------------
     'fat' <-> 'cat'
    (1 row)

    --指定距离。
    gaussdb=# SELECT tsquery_phrase(to_tsquery('fat'), to_tsquery('cat'), 2);
     tsquery_phrase
    -----------------
     'fat' <2> 'cat'
    (1 row)
[[PDF_PAGE physical=400 printed=351]]
●   querytree(query tsquery)
    描述：获取tsquery类型的词汇可加索引的部分。
    返回类型：text
    示例：
    gaussdb=# SELECT querytree('foo & ! bar'::tsquery);
     querytree
    -----------
     'foo'
    (1 row)

●   setweight(tsvector, "char")
    描述：给tsvector类型的每个元素分配权重值，权重的取值为：'A'、'B'、'C'、
    'D'。
    返回类型：tsvector
    示例：
    gaussdb=# SELECT setweight('fat:2,4 cat:3 rat:5B'::tsvector, 'A');
             setweight
    -------------------------------
     'cat':3A 'fat':2A,4A 'rat':5A
    (1 row)

●   strip(tsvector)
    描述：删除tsvector类型单词中的位置信息和权重值。
    返回类型：tsvector
    示例：
    gaussdb=# SELECT strip('fat:2,4 cat:3 rat:5A'::tsvector);
          strip
    -------------------
     'cat' 'fat' 'rat'
    (1 row)

●   to_tsquery([ config regconfig , ] query text)
    描述：标准化单词，并转换为tsquery类型。具体功能介绍详见解析查询。
    返回类型：tsquery
    示例：
    gaussdb=# SELECT to_tsquery('english', 'The & Fat & Rats');
      to_tsquery
    ---------------
     'fat' & 'rat'
    (1 row)

●   to_tsvector([ config regconfig , ] document text)
    描述：将文档内容标准化，去除停用词，排序并去重。转换为tsvector类型。具体
    功能介绍详见解析文档。
    返回类型：tsvector
    示例：
    gaussdb=# SELECT to_tsvector('english', 'The Fat Rats');
       to_tsvector
    -----------------
     'fat':2 'rat':3
    (1 row)

●   to_tsvector_for_batch([ config regconfig , ] document text)
    描述：将文档内容标准化，去除停用词，排序并去重。转换为tsvector类型。
    返回类型：tsvector
[[PDF_PAGE physical=401 printed=352]]
    示例：
    gaussdb=# SELECT to_tsvector_for_batch('english', 'The Fat Rats');
       to_tsvector
    -----------------
     'fat':2 'rat':3
    (1 row)

●   ts_headline([ config regconfig, ] document text, query tsquery [, options
    text ])
    描述：高亮显示查询的匹配项。具体功能介绍详见高亮搜索结果。
    返回类型：text
    示例：
    gaussdb=# SELECT ts_headline('x y z', 'z'::tsquery);
     ts_headline
    --------------
     x y <b>z</b>
    (1 row)

●   ts_rank([ weights float4[], ] vector tsvector, query tsquery [, normalization
    integer ])
    描述：文档查询排名。具体功能介绍详见排序查询结果。
    返回类型：float4
    示例：
    gaussdb=# SELECT ts_rank('hello world'::tsvector, 'world'::tsquery);
     ts_rank
    ----------
     .0607927
    (1 row)

●   ts_rank_cd([ weights float4[], ] vector tsvector, query tsquery [, normalization
    integer ])
    描述：排序文件查询使用覆盖密度。具体功能介绍详见排序查询结果。
    返回类型：float4
    示例：
    gaussdb=# SELECT ts_rank_cd('hello world'::tsvector,'world'::tsquery);
     ts_rank_cd
    ------------
            0
    (1 row)

●   ts_rewrite(query tsquery, target tsquery, substitute tsquery)
    描述：替换目标tsquery类型的单词。具体功能介绍详见查询重写。
    返回类型：tsquery
    示例：
    gaussdb=# SELECT ts_rewrite('a & b'::tsquery, 'a'::tsquery, 'foo|bar'::tsquery);
          ts_rewrite
    -------------------------
     'b' & ( 'foo' | 'bar' )
    (1 row)

●   ts_rewrite(query tsquery, select text)
    描述：使用SELECT命令的结果替代目标中tsquery类型的单词。具体功能介绍详见
    查询重写。
    返回类型：tsquery
    示例：
    gaussdb=# SELECT ts_rewrite('world'::tsquery, 'select ''world''::tsquery, ''hello''::tsquery');
     ts_rewrite
[[PDF_PAGE physical=402 printed=353]]
           ------------
            'hello'
           (1 row)
