1.6.53 DATABASE LINK 函数
         ●   close_database_link(dblink_name name)
             描述：通过DBLink名称主动关闭当前session下该DBLink的连接，不允许关闭存在
             活跃事务的dblink。

             表 1-282 close_database_link(dblink_name name)参数说明
              名称                       类型       输入/输出          描述

              dblink_name              nam      输入             DBLink的名称。
                                       e

              close_database_li        bool     输出             关闭DATABASE LINK结果（t: 成功，
              nk                       ean                     f: 失败）。



             示例：
             gaussdb=# SELECT close_database_link('xxx');
              close_database_link
             ---------------------
              t
             (1 row)

             gaussdb=# BEGIN;
             BEGIN
             gaussdb=# SELECT * FROM t1@dblink;
             c1 | c2 | c3
             ----+----+----
             1||
             (1 row)
             gaussdb=# INSERT INTO t1@dblink VALUES (2,0,0);
             INSERT 0 1
             gaussdb=# SELECT * FROM t1@dblink;
             c1 | c2 | c3
             ----+----+----
             1||
             2|0|0
             (2 rows)
             gaussdb=# SELECT close_database_link('dblink');
             ERROR: Dblink dblink is in use.
             CONTEXT: referenced column: close_database_link
             gaussdb=# END;
             ROLLBACK

         ●   gs_ora_diag(dblink_name name DEFAULT NULL::name)
             描述：该函数只能获取连接Oracle库的DBLink对应的信息。通过DBLink名称获取
             gs_ora_fdw版本、GaussDB版本、Oracle数据库客户端版本以及Oracle数据库服
[[PDF_PAGE physical=1040 printed=991]]
    务端版本信息。当参数为NULL时，如果查询用户是管理员用户还会返回
    ORACLE_HOME、ORACLE_SID、TNS_ADMIN、TWO_TASK、 LDAP_ADMIN等
    信息，非管理员用户不显示。

    表 1-283 gs_ora_diag(dblink_name name DEFAULT NULL::name)参数说明
     名称                            类型         输入/输出               描述

     dblink_name                   nam        输入                  DBLink的名称。
                                   e

     gs_ora_diag                   text       输出                  该DBLink的diag信息。



    示例：
    --管理员用户。
    gaussdb=# SELECT gs_ora_diag('xxx');
                                 gs_ora_diag
    --------------------------------------------------------------------------------------
     gs_ora_fdw 1.0.0, GaussDB 9.2.4, Oracle client 19.24.0.0.0, Oracle server 19.0.0.0.0

    (1 row)

    --普通用户。

                                 gs_ora_diag

     gs_ora_fdw 1.0.0, GaussDB 9.2.4, Oracle client 19.24.0.0.0, Oracle server 19.0.0.0.0

●   gs_ora_fdw_handler()
