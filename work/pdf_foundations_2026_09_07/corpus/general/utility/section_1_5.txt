表 1-29 常量和宏

参数            描述                 示例

CURRENT_CA    当前数据库。             testdb=# SELECT CURRENT_CATALOG;
                                 current_database
TALOG                            ------------------
                                 testdb
                                 (1 row)

CURRENT_RO    当前用户。              gaussdb=# SELECT CURRENT_ROLE;
                                 current_user
LE                               --------------
                                 omm
                                 (1 row)

CURRENT_SC    当前数据库模式。           gaussdb=# SELECT CURRENT_SCHEMA;
                                 current_schema
HEMA                             ----------------
                                 public
                                 (1 row)

CURRENT_US    当前用户。              gaussdb=# SELECT CURRENT_USER;
                                 current_user
ER                               --------------
                                 omm
                                 (1 row)

LOCALTIMEST   当前会话时间（无时          gaussdb=# SELECT LOCALTIMESTAMP;
                                        timestamp
AMP           区）。                ----------------------------
                                 2015-10-10 15:37:30.968538
                                 (1 row)

NULL          空值。                -

SESSION_USE   当前系统用户。            gaussdb=# SELECT SESSION_USER;
                                 session_user
R                                --------------
                                 omm
                                 (1 row)

SYSDATE       当前系统日期。            gaussdb=# SELECT SYSDATE;
                                 sysdate
                                 ---------------------
                                 2015-10-10 15:48:53
                                 (1 row)

USER          当前用户，此用户为          gaussdb=# SELECT USER;
                                 current_user
              CURRENT_USER的别名。   --------------
                                 omm
                                 (1 row)
