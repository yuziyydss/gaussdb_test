1.3.20 SET 类型
         SET类型是包含字符串成员的集合数据类型，需在创建表字段时定义。

规格描述
         ●   SET类型成员个数最大为64个，最小为1个。不能定义为空集。
         ●   成员名称长度最大为255个字符，允许使用空字符串作为成员名称。成员名称必须
             是字符常量，且不能是计算后得到的字符常量，如SET('a' || 'b', 'c')。
[[PDF_PAGE physical=160 printed=111]]
       ●   成员名称不能包含逗号，成员名称不能重复。
       ●   不支持创建SET类型的数组或域类型。
       ●   只有在sql_compatibility参数值为B兼容模式下支持SET类型。
       ●   不支持SET类型作为分区表的分区键。
       ●   使用DROP TYPE删除SET类型时，必须指定CASCADE选项，且关联的表字段也会
           被同时删除。
       ●   开启回收站功能时，如果表中包含SET类型的字段，则表被删除时，不会进入到回
           收站中，而是直接删除。
       ●   不支持通过ALTER TABLE将SET类型字段的数据类型修改为其他SET类型。
       ●   表或者SET类型关联的表字段被删除时，或表字段的SET类型修改为其他类型时，
           对应的SET数据类型也会被同步删除。
       ●   不支持使用CREATE TABLE { AS | LIKE }语法创建包含SET类型的表。
       ●   SET类型随表字段创建，其名称是组合而成的。如果Schema中已经存在同名的数
           据类型，则创建SET类型会失败。
       ●   SET类型支持与int2、int4、int8、text类型进行比较操作（=、<、>、<、<=、>、
           >=）。
       ●   SET类型支持与int2、int4、int8、float4、float8、numeric、char、varchar、
           text、nvarchar2数据类型的转换。

注意事项
       ●   SET类型的表字段值必须是SET类型定义的集合的子集。如：
           gaussdb=# CREATE TABLE employee (
             name text,
             site SET('siteA','siteB','siteC','siteD')
           );

       ●   site字段的值必须是上述集合定义中的子集，可以是空集合，如果提供的值在SET
           定义中的成员中不存在，会报错。如：
           gaussdb=# INSERT INTO employee values('zhangsan', 'siteC,siteB');
           INSERT 0 1
           gaussdb=# INSERT INTO employee VALUES ('zhangsan', 'siteE');
           ERROR: invalid input value for set employee_site_set: 'siteE'

       ●   INSERT时无论用户提供的成员值顺序是怎样的，INSERT成功后，查询到的SET类
           型的值，其成员都是按照定义时的顺序输出的。
           gaussdb=# SELECT * FROM employee;
             name |        site
           ----------+-----------------
            zhangsan | siteB,siteC
           (1 rows)

       ●   SET类型是以bitmap的方式存储的。SET类型的成员按照定义时的顺序，赋予不同
           的值。如：SET('siteA','siteB','siteC','siteD')的类型，对应的值如下：

           表 1-26 SET 成员与其对应的数值

            SET成员                                  成员值                         二进制值

            'siteA'                                1                           0001

            'siteB'                                2                           0010

            'siteC'                                4                           0100
[[PDF_PAGE physical=161 printed=112]]
 SET成员                            成员值               二进制值

 'siteD'                          8                 1000




因此，当给SET类型的字段赋值为数值时，会转换为对应的子集。例如：数字9对
应的二进制值为1001，对应的子集是'siteA,siteD'。
gaussdb=# INSERT INTO employee values('lisi', 9);
INSERT 0 1
gaussdb=# SELECT * FROM employee;
   name |        site
----------+-----------------
 zhangsan | siteA,siteC
 lisi   | siteA,siteD
(2 rows)
gaussdb=# DROP TABLE employee;
