1.3.25 ROWID 类型
        ROWID数据类型用于标识表中的数据行，包含定位该行所需的关键信息，可实现对表
        中数据行的快速定位。
        ROWID数据类型由29个BASE64编码的字符组成，各个字符串的含义如表1-28所示：

        表 1-28 ROWID 类型字段含义
         字段          含义              字符长   取值范围（BASE64编码）
                                     度

         reserve_f   保留位。            6     当前版本0（AAAAAA）。
         lag

         node_slic   节点的分片编号。        3     0（AAA）。
         e

         bucket_i    hash bucket表的   3     65535（P//）。
         d           bucket编号。

         table_oid   表的oid。          6     最小值0（AAAAAA），最大值
                                           4294967295（D/////）。

         row_no      行的编号。           11    最小值0（AAAAAAAAAAA），最大值
                                           9223372036854775807
                                           （H//////////）。
[[PDF_PAGE physical=174 printed=125]]
            说明

          ROWID类型不支持以下操作：
          ● ROWID类型不支持作为表的分区键。
          ● ROWID类型不支持HTAP。
          ● ROWID类型仅支持A兼容性数据库。
          ● ROWID类型不支持数据脱敏策略。
          ● ROWID类型不可作为自定义范围类型的subtype。详细可见范围类型章节内容。
          ● ROWID类型仅支持JDBC驱动。


示例
      -- 创建表
      gaussdb=# CREATE TABLE rowid_test(id INT, rwd ROWID);
      CREATE TABLE

      -- 插入数据，值为NULL
      gaussdb=# INSERT INTO rowid_test VALUES(1, NULL);
      INSERT 0 1

      -- 插入数据，满足ROWID格式
      gaussdb=# INSERT INTO rowid_test VALUES(2, 'AAAAAAAAAP//BBBBBAAAAAAAAAAAC');
      INSERT 0 1
      gaussdb=# INSERT INTO rowid_test VALUES(3, 'AAAAAAAAAP//BBBd+AAAAAAAA901/');
      INSERT 0 1
      gaussdb=# INSERT INTO rowid_test VALUES(4, 'AAAAAAAAAP//A12i+AAAAAAAAItn/');
      INSERT 0 1
      gaussdb=# INSERT INTO rowid_test VALUES(5, 'AAAAAAAAAP//CC+uJAAAAAAGASIi9');
      INSERT 0 1

      -- 插入数据，不满足ROWID格式
      gaussdb=# INSERT INTO rowid_test VALUES(6, 'AAAAAAAAAP//BBBd+AAAAAAAA@@@@');
      ERROR: Invalid rowid.
      LINE 1: INSERT INTO rowid_test VALUES(6, 'AAAAAAAAAP//BBBd+AAAAAAAA@...
                                ^
      CONTEXT: referenced column: rwd

      -- 插入数据，不满足ROWID值范围
      gaussdb=# INSERT INTO rowid_test VALUES(6, 'AAAAAAAAAP/////d+AAAAAAAA901/');
      ERROR: Invalid rowid.
      LINE 1: INSERT INTO rowid_test VALUES(6, 'AAAAAAAAAP/////d+AAAAAAAA9...
                                ^
      CONTEXT: referenced column: rwd

      -- 查看数据
      gaussdb=# SELECT * FROM rowid_test;
       id |          rwd
      ----+-------------------------------
        1|
        2 | AAAAAAAAAP//BBBBBAAAAAAAAAAAC
        3 | AAAAAAAAAP//BBBd+AAAAAAAA901/

      -- 删除表
      gaussdb=# DROP TABLE IF EXISTS rowid_test;
      DROP TABLE


操作符
      ROWID类型支持比较操作符（=、<>、<、>、<=、>=），当与不支持隐式转换成
      ROWID的数据类型进行比较操作时，报错“Inconsistent datatypes”。关于比较操作
      符详细可见比较操作符章节内容。
[[PDF_PAGE physical=175 printed=126]]
ROWID类型的比较规则是按照node_slice、table_oid、bucket_id、row_no字段数值
依次进行比较。

示例

索引
     ROWID类型普通列支持BTREE/UBTREE索引，详情请参见CREATE INDEX章节内容。
     在使用ROWID类型普通列进行JOIN操作时，支持HASH JOIN算子，详情请参见连接查
     询章节内容。
     示例
     gaussdb=# CREATE TABLE t1(b ROWID, c INT) WITH (storage_type=ustore);
     CREATE TABLE
     gaussdb=# CREATE TABLE t2(b ROWID, c INT) WITH (storage_type=astore);
     CREATE TABLE
     gaussdb=# INSERT INTO t1 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC', generate_series(1,100));
     INSERT 0 100
     gaussdb=# INSERT INTO t2 VALUES('AAAAAAAAAP//BBBBBAAAAACdAAAAC', generate_series(1,100));
     INSERT 0 100
     gaussdb=# --BTREE索引
     gaussdb=# CREATE INDEX t1_rowid_index ON t1 USING BTREE (b);
     NOTICE: Index type btree is converted to index type ubtree.
     CREATE INDEX
     gaussdb=# CREATE INDEX t2_rowid_index ON t2 USING BTREE (b rowid_ops);
     CREATE INDEX
     gaussdb=# \d t1
          Table "public.t1"
      Column | Type | Modifiers
     --------+---------+-----------
      b     | rowid |
      c     | integer |
     Indexes:
        "t1_rowid_index" ubtree (b) WITH (storage_type=USTORE) TABLESPACE pg_default

     gaussdb=# \d t2
        Table "public.t2"

类型转换
       ROWID类型和字符串类型允许进行隐式类型转换。
       示例
[[PDF_PAGE physical=179 printed=130]]
gaussdb=# CREATE TABLE t1(a ROWID);
CREATE TABLE
gaussdb=# INSERT INTO t1 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::BPCHAR(29));
INSERT 0 1
gaussdb=# INSERT INTO t1 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::VARCHAR(29));
INSERT 0 1
gaussdb=# INSERT INTO t1 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::NVARCHAR2(29));
INSERT 0 1
gaussdb=# INSERT INTO t1 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::TEXT);
INSERT 0 1
gaussdb=# CREATE TABLE t2(a BPCHAR(29));
CREATE TABLE
gaussdb=# INSERT INTO t2 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::ROWID);
INSERT 0 1
gaussdb=# CREATE TABLE t3(a VARCHAR(29));
CREATE TABLE
gaussdb=# INSERT INTO t3 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::ROWID);
INSERT 0 1
gaussdb=# CREATE TABLE t4(a NVARCHAR2(29));
CREATE TABLE
gaussdb=# INSERT INTO t4 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::ROWID);
INSERT 0 1
gaussdb=# CREATE TABLE t5(a TEXT);
CREATE TABLE
gaussdb=# INSERT INTO t5 VALUES('AAAAAAAAAP//BBBBBAAAAAAAAAAAC'::ROWID);
INSERT 0 1
gaussdb=# DROP TABLE IF EXISTS t1;
DROP TABLE

DROP TABLE
gaussdb=# DROP TABLE IF EXISTS t3;
