1.13.10.43 DROP TEXT SEARCH CONFIGURATION


             须知

           该功能为内部使用功能，不建议用户使用。


功能描述
           删除一个已有文本搜索配置。
[[PDF_PAGE physical=1695 printed=1646]]
注意事项
       仅文本搜索配置的所有者可以执行该操作。

语法格式
       DROP TEXT SEARCH CONFIGURATION [ IF EXISTS ] name [ CASCADE | RESTRICT ];




参数说明
       ●    IF EXISTS
            判断指定的文本搜索配置是否存在。
            –    如果指定的文本搜索配置存在，则删除成功。
            –    如果指定的文本搜索配置不存在，不会进行删除操作，仅产生一个NOTICE提
                 示，用于告知指定的文本搜索配置不存在。
       ●    name
            要删除的文本搜索配置名称，可以使用模式进行具体指定。
       ●    CASCADE | RESTRICT
            可选，是否级联删除依赖于该文本搜索配置的对象。未指定时，默认为
            RESTRICT。
            –    CASCADE：级联删除依赖文本搜索配置的对象。
            –    RESTRICT：若存在依赖于文本搜索配置的对象，则拒绝删除该文本搜索配
                 置。

示例
       请参见CREATE TEXT SEARCH CONFIGURATION章节的示例。
