8.3.16.205 PLAN_TABLE
            PLAN_TABLE显示用户通过执行EXPLAIN PLAN收集到的计划信息。计划信息的生命周
            期是session级别，session退出后相应的数据将被清除。同时不同session和不同user间
            的数据是相互隔离的。该视图同时存在PG_CATALOG和SYS schema下。

表 8-487 PLAN_TABLE 字段
名称                类型                  描述

statement_id      character           用户输入的查询标签。
                  varying(30)

plan_id           bigint              查询标识。

id                integer             查询生成的计划中的每一个执行算子
                                      的编号。

operation         character           计划中算子的操作描述。
                  varying(30)

options           character           操作选项。
                  varying(255)

object_name       name                操作对应的对象名，非查询中使用到
                                      的对象别名。来自于用户定义。

object_type       character           对象类型。
                  varying(30)

object_owner      name                对象所属schema，来自于用户定
                                      义。

projection        character           操作输出的列信息。
                  varying(4000)

cost              double precision    优化器对算子估算的执行代价。

cardinality       double precision    优化器对算子估算的结果行数。

remarks           character           暂不支持，值为NULL。
                  varying(4000)

timestamp         timestamp(0)        暂不支持，值为NULL。
                  without time zone   说明
                                       在初始化数据库时，若指定GUC参数
                                       mapping_date_to_datea的值为on，则
                                       该字段的类型会变更为datea。

object_node       character           暂不支持，值为NULL。
                  varying(128)

object_alias      character           暂不支持，值为NULL。
                  varying(261)

object_instance   numeric             暂不支持，值为NULL。

optimizer         character           暂不支持，值为NULL。
                  varying(255)

search_columns    numeric             暂不支持，值为NULL。

parent_id         numeric             暂不支持，值为NULL。

depth             numeric             暂不支持，值为NULL。

    说明

  ● object_type取值范围为PG_CLASS中定义的relkind类型（TABLE普通表，INDEX索引，
    SEQUENCE序列，VIEW视图，COMPOSITE TYPE复合类型，TOASTVALUE TOAST表）和计
    划使用到的rtekind(SUBQUERY, JOIN, FUNCTION, VALUES, CTE, REMOTE_QUERY)。
  ● object_owner对于RTE来说是计划中使用的对象描述，非用户定义的类型不存在
    object_owner。
  ● statement_id、object_name、object_owner、projection字段内容遵循用户定义的大小写存
    储，其它字段内容采用大写存储。
  ● 支持用户对PLAN_TABLE进行SELECT和DELETE操作，不支持其它DML操作。
