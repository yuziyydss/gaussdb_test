1.13.9.46 CREATE SERVER

功能描述
            创建一个外部服务器。外部服务器是其他同构数据库信息的载体。

注意事项
            OPTIONS中的敏感字段（如password）在使用多层引号时，语义和不带引号的场景是
            不同的，因此不会被识别为敏感字段进行脱敏。

语法格式
            CREATE SERVER server_name
              FOREIGN DATA WRAPPER fdw_name
              [ OPTIONS ( { option_name ' value ' } [, ...] ) ];




参数说明
            ●     server_name
                  创建的外部服务器名称。
                  取值范围：字符串，要符合标识符命名规范且最大长度不超过63个字符。
            ●     FOREIGN DATA WRAPPER fdw_name
                  指定外部数据封装器的名称。
[[PDF_PAGE physical=1529 printed=1480]]
            取值范围：dist_fdw、log_fdw、file_fdw。其中：log_fdw和file_fdw仅为语法兼
            容，可以创建外表，无实际使用意义，不做额外使用说明。
       ●    OPTIONS ( { option_name ' value ' } [, ...] )
            用于指定外部服务器的各类参数。这个子句为服务器指定选项，这些选项通常定
            义该服务器的连接细节，但是实际的名称和值取决于该服务器的外部数据包装
            器。除了libpq支持的连接参数外，还额外提供以下参数：
            –    fdw_startup_cost
                 执行一个外表扫描时的启动耗时估算。通常包含建立连接、远端对请求的分
                 析和生成计划的耗时。默认值为100。
                 取值范围：大于0的实数。
            –    fdw_typle_cost
                 在远端服务器上对每一个元组进行扫描时的额外消耗，通常表示数据在服务
                 器间传输的额外消耗。默认值为0.01。
                 取值范围：大于0的实数。

示例
       建立一个外部服务器，其中file_fdw为数据库中存在的FOREIGN DATA WRAPPER。
       --创建外部服务器。
       gaussdb=# CREATE SERVER my_server FOREIGN DATA WRAPPER file_fdw;

       --删除外部服务器。
       gaussdb=# DROP SERVER my_server;

       建立另外一个同构数据库的外部服务器，其中log_fdw为数据库中存在的FOREIGN
       DATA WRAPPER。
       --创建外部服务器。
       gaussdb=# CREATE SERVER server_remote FOREIGN DATA WRAPPER log_fdw OPTIONS
          (address '10.146.187.231:8000,10.180.157.130:8000' ,
         dbname 'test',
         username 'test',
         password '********'
       );

       --删除外部服务器。
       gaussdb=# DROP SERVER server_remote;
