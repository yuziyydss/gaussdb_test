8.2.19.63 PG_RESOURCE_POOL
           PG_RESOURCE_POOL系统表提供了数据库资源池的信息。

           表 8-139 PG_RESOURCE_POOL 字段

            名称             类型        描述

            oid            oid       行标识符（隐含属性，必须明确选择）。

            respool_name   name      资源池名称。

            mem_percent    integer   内存配置的百分比。
[[PDF_PAGE physical=5006 printed=4957]]
名称               类型        描述

cpu_affinity     bigint    CPU绑定core的数值。

control_group    name      资源池所在的control group名称。

active_stateme   integer   资源池上最大的并发数。
nts

max_dop          integer   只用于扩容的接口，表示数据重分布时，扫描并发
                           度。

memory_limit     name      资源池最大的内存。

parentid         oid       父资源池OID。

io_limits        integer   每秒触发I/O的次数上限。单位是万次/秒。

io_priority      name      I/O利用率高达90%时，重消耗I/O作业进行I/O资源
                           管控时关联的优先级等级。

nodegroup        name      表示资源池所在的逻辑数据库的名称。（集中式不支
                           持该字段）

is_foreign       boolean   表示资源池是否用于控制逻辑数据库之外的用户。
                           （集中式不支持该字段）
                           ● true：表示资源池用来控制不属于当前资源池的
                             普通用户的资源。
                           ● false：表示不控制不属于当前资源池的普通用户
                             的资源。

max_worker       integer   只用于扩容的接口，表示扩容数据重分布时，表内插
                           入并发度。

max_connectio    integer   最大连接数，用来限制资源池可使用的最大连接数。
ns

max_dynamic_     name      资源池允许使用的最大动态内存值。
memory

max_shared_m     name      资源池允许使用的最大共享内存值。
emory

max_concurre     integer   资源池允许使用的最大并发数。
ncy




注：max_dop和max_worker用于扩容，不适用于集中式。
