1.13.13.1 GENERATED UPDATE SYSTEM OBJECT

功能描述
           生成系统对象的升级回滚脚本文件，在升级回滚时由OM调用。内部语法，不建议用户
           使用。

注意事项
           ●   此语句仅支持升级中通过OM调用，即在GUC参数upgrade_mode不为0且GUC参
               数application_name设置为"OM"时此语句可被执行。
           ●   只有初始用户有权限执行此语句。

语法格式
           GENERATED UPDATE SYSTEM OBJECT;
