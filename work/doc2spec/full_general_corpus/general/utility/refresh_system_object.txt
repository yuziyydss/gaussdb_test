1.13.18.4 REFRESH SYSTEM OBJECT

功能描述
            将系统对象的版本信息刷新到系统表GS_SYSTEM_OBJECTS_VERSION中，用于升级时
            判断系统对象的变化情况。
            从507.0之前的版本升级时调用。内部语法，不建议用户使用。

注意事项
            ●   此语句仅支持升级阶段调用，即在GUC参数upgrade_mode不为0时此语句可被执
                行。
[[PDF_PAGE physical=1784 printed=1735]]
       ●   只有初始用户有权限执行此语句。

语法格式
       REFRESH SYSTEM OBJECT;
