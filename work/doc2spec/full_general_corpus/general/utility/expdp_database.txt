1.13.11.2 EXPDP DATABASE

功能描述
            导出DATABASE的全部物理文件。

语法格式
            EXPDP DATABASE db_name LOCATION = 'directory';
[[PDF_PAGE physical=1707 printed=1658]]
参数说明
       ●   db_name
           导出的库名。
       ●   directory
           导出文件的存储目录。


示例
       --EXPDP DATABASE语法用于细粒度备份恢复，由备份恢复工具调用，用户直接调用会报错，错误信息：
       ERROR: Only auxdb is allowed to execute expdp cmd.
       gaussdb=# EXPDP DATABASE test LOCATION = '/data1/expdp/database';
