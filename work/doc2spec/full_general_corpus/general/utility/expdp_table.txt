1.13.11.4 EXPDP TABLE

功能描述
            导出与表相关的索引、sequence、分区、toast、toast index等全部文件。


语法格式
            EXPDP TABLE table_name LOCATION = 'directory';




参数说明
            ●    table_name
                 导出的表名。
            ●    directory
                 导出文件的存储目录。


示例
            --EXPDP TABLE语法用于细粒度备份恢复，由备份恢复工具调用，用户直接调用会报错，错误信息：ERROR:
            Only auxdb is allowed to execute expdp cmd.
            gaussdb=# EXPDP TABLE test_t LOCATION = '/data1/expdp/table0';
