1.13.10.44 DROP TEXT SEARCH DICTIONARY


               须知

           该功能为内部使用功能，不建议用户使用。


功能描述
           删除一个已有全文检索词典。

注意事项
           ●   预定义词典模板不支持删除操作。
           ●   只有词典的所有者可以执行该操作，系统管理员默认拥有此权限。
           ●   请谨慎执行显式指定CASCADE操作，该操作将级联删除使用该词典的文本搜索配
               置（TEXT SEARCH CONFIGURATION）。
[[PDF_PAGE physical=1696 printed=1647]]
语法格式
       DROP TEXT SEARCH DICTIONARY [ IF EXISTS ] name [ CASCADE | RESTRICT ];




参数说明
       ●    IF EXISTS
            判断指定的全文检索词典是否存在。
            –    如果指定的全文检索词典存在，则删除成功。
            –    如果指定的全文检索词典不存在，不会进行删除操作，仅产生一个NOTICE提
                 示，用于告知指定的全文检索词典不存在。
       ●    name
            要删除的词典名称（可指定模式名，否则默认在当前模式下）。
            取值范围：已存在的词典名。
       ●    CASCADE | RESTRICT
            可选，是否级联删除依赖于该词典的对象。未指定时，默认为RESTRICT。
            –    CASCADE：自动删除依赖于该词典的对象，并依次删除依赖于这些对象的所
                 有对象。
            –    RESTRICT：如果存在依赖词典的对象，则拒绝删除该词典。

示例
       --创建词典english。
       gaussdb=# CREATE TEXT SEARCH DICTIONARY english (
          TEMPLATE = simple
       );

       --删除词典english。
       gaussdb=# DROP TEXT SEARCH DICTIONARY english;
