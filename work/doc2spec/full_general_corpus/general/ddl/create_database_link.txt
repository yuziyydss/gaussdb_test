1.13.9.17 CREATE DATABASE LINK

功能描述
            创建DATABASE LINK对象。

注意事项
            ●   DATABASE LINK详细说明请参见《开发指南》中“特性使用指导 > DATABASE
                LINK”章节。
            ●   DATABASE LINK特性只能在A兼容模式数据库下使用。
            ●   禁止使用DATABASE LINK连接初始用户，禁止初始用户创建、修改和删除
                DATABASE LINK对象。
            ●   DATABASE LINK创建时，不会对其是否可连接成功进行验证，如果缺乏相关的关
                键字，可能会在使用时报错。
[[PDF_PAGE physical=1424 printed=1375]]
       ●    升级未提交情况下无法创建使用DATABASE LINK。
       ●    当未指定CURRENT_USER或CONNECT TO连接串时（即使用当前数据库初始用户
            名和空的密码连接），会连接失败。
       ●    连接GaussDB时，使用localhost、127.0.0.1或本机IP及对应端口可连接当前实例
            数据库。

语法格式
       CREATE [ PUBLIC ] DATABASE LINK dblink [ CONNECT TO { CURRENT_USER | 'user' IDENTIFIED BY
       'password' } ] [name] [ USING ( option 'value' [...]) ];

       当name为空时，连接GaussDB数据库option如下：
       { HOST | PORT | DBNAME | FETCH_SIZE }

       当name为OCI时，连接Oracle数据库option如下：
       { DBSERVER | ISOLATION_LEVEL | MAX_LONG | STRIP_ZEROS | PREFETCH | LOB_PREFETCH | TIME_OUT |
       CASE_INSENSITIVE }


参数说明
       ●    PUBLIC
            指定创建对所有用户可见的公共数据库连接。如果未指定，则为私有的数据库连
            接，仅对当前用户可用。
       ●    dblink
            创建的DATABASE LINK的名字。
       ●    user
            创建的DATABASE LINK连接远程数据库使用的用户名。
       ●    password
            创建的DATABASE LINK连接远程数据库使用的用户对应的密码。
       ●    CURRENT_USER
            使用当前数据库初始用户名和空密码连接。
       ●    name
            当前只支持OCI字符串或省略，指定则创建连接Oracle数据库，省略则创建连接
            GaussDB数据库。
       ●    USING ( option 'value' [, ... ] )
            可选，USING可选择指定要连接的数据库的IP地址、端口号、远程数据库名称等
            参数。
            连接GaussDB支持的options包括：
            –    host：指定连接的数据库IP地址，不指定时默认为空。可以指定多个IP地址，
                 以逗号（,）进行分隔，当前不支持密态数据库。
            –    port：指定连接的端口号，不指定时默认为5432。
            –    dbname：指定连接的数据库名称，不指定时默认为连接远程使用的用户名。
            –    fetch_size：从远程每次获取数据量大小，取值范围[0, 2147483647]，默认
                 值为100。
            连接Oracle数据库支持的options包括：
            –    dbserver：指定连接Oracle数据库的实例信息，一般格式为[ip]:端口/实例
                 名，当地址为IPv4地址时可省略“[]”符号，当地址为IPv6地址时不可省略
                 “[]”符号。如果要使用SSL进行连接，需要指定TNS节点名，具体信息及须
                 知请参见CREATE DATABASE LINK章节中的SSL连接说明。
[[PDF_PAGE physical=1425 printed=1376]]
–   isolation_level：指定通过DBLink开启Oracle数据库事务的隔离级别，默认为
    serializable，可选项有serializable、read_committed、read_only。
–   max_long：指定远程数据库表中long、long raw类型的列的最大长度，取值
    范围[1, 1073741823]。当前该参数为预置参数，暂不生效。
–   strip_zeros：连接远程数据库时，如果设置为yes/on/true，则会将字符串中
    的ASCII 0字符删除。
–   prefetch：连接远程数据库Scan时每次fetch的数据行数，取值范围[1,
    1000]，默认值为50。
–   lob_prefetch：连接远程数据库Scan时lob类型每次fetch的字节大小，取值范
    围[0, 536870912]，默认值为1048576。当前该参数为预置参数，暂不生
    效。
–   time_out：连接远程数据库的执行超时时间，取值范围[0, 2147483647]。默
    认值为0，表示不会超时。
–   case_insensitive：指定连接远程数据库时大小写敏感开关，默认为关。使用
    DBLink查询Oracle数据库的表名、Schema名及列名时遵循如下规则：

    ▪   选项设置为on时：
        ○   DBLink会默认将表名及Schema名转为大写处理，查询时无需显式
            指定查询大写表名，默认查询远程数据库名称为大写的表及
            Schema。
        ○   列名在本地数据库默认转成小写存储，无法使用双引号大写列名查
            询。
        ○   无法查询远程数据库创建的小写及大小写混用的表名、Schema名及
            列名。

    ▪   选项设置为off时：
        ○   大写表名、Schema名及列名，DBLink查询时需要使用双引号加大
            写查询。
        ○   大小写混用的表名、Schema名及列名，DBLink查询时需要使用双
            引号加大小写混用查询。
        ○   小写的表名、Schema名及列名，DBLink查询时可使用不带引号的
            默认查询或使用双引号加小写查询。
[[PDF_PAGE physical=1426 printed=1377]]
              须知

          连接Oracle数据库使用SSL连接参考配置方法：
          1. GaussDB端客户自行安装的OCI客户端，sqlnet.ora中配置wallet路径及SSL相
             关属性，wallet路径为证书位置。具体格式如下：
             WALLET_LOCATION =
             (SOURCE =
             (METHOD = FILE)
             (METHOD_DATA =
             (DIRECTORY = /home/instantclient/wallet)
             )
             )
             -- 新增TCPS选项
             SQLNET.AUTHENTICATION_SERVICES= (TCPS, NTS, BEQ)
             SSL_CLIENT_AUTHENTICATION = TRUE
             SSL_CIPHER_SUITES = (SSL_RSA_WITH_AES_256_CBC_SHA, SSL_RSA_WITH_3DES_EDE_CBC_SHA)
          2. 在tnsnames.ora中配置TNS，与服务端TCPS协议对应的TNS一致。具体格式如
             下：
             ORA_SSL =
             (DESCRIPTION =
             (ADDRESS = (PROTOCOL = TCPS)(HOST = xxxx)(PORT = xxxx))
             (CONNECT_DATA =
             (SERVER = DEDICATED)
             (SERVICE_NAME = ORA)
             )
             )
          3. 创建DATABASE LINK时，DBSERVER选项指定配置的TNS名，对应上一步中的
             ORA_SSL。
          4. 连接Oracle数据库。
             若首次连接Oracle数据库时，需保证tnsnames.ora文件存在。若tnsnames.ora
             文件不存在则需要正确配置并重启GaussDB数据库后才可正常使用DATABASE
             LINK连接。


示例
     -- 前置条件。
     gaussdb=# CREATE USER local_user WITH SYSADMIN PASSWORD '********';
     CREATE ROLE
     gaussdb=# SET ROLE local_user PASSWORD '********';
     SET

     -- 创建私有DBLink，host也可以是IPv6地址。
     gaussdb=# CREATE DATABASE LINK private_dblink CONNECT TO 'remote_user' IDENTIFIED BY '********'
     USING (host '***.***.***.***',port '*****',dbname 'remote_db');
     CREATE DATABASE LINK

     -- 创建公共DBLink，host也可以是IPv6地址。
     gaussdb=# CREATE PUBLIC DATABASE LINK public_dblink CONNECT TO 'remote_user' IDENTIFIED BY
     '********' USING (host '***.***.***.***',port '*****',dbname 'remote_db');
     CREATE DATABASE LINK

     -- 创建公共连接Oracle库的DBLink。
     gaussdb=# CREATE PUBLIC DATABASE LINK public_dblink_to_o CONNECT TO 'oracle_user' IDENTIFIED BY
     '********' OCI USING (dbserver '***.***.***.***/orcl', prefetch '100');
     CREATE DATABASE LINK

     -- 创建使用SSL连接Oracle库的DBLink。
     gaussdb=# CREATE PUBLIC DATABASE LINK public_dblink_SSL CONNECT TO 'oracle_user' IDENTIFIED BY
     '********' OCI USING (dbserver 'ORA_SSL');
     CREATE DATABASE LINK

     -- 清理环境。
[[PDF_PAGE physical=1427 printed=1378]]
       gaussdb=# DROP PUBLIC DATABASE LINK private_dblink;
       DROP DATABASE LINK
       gaussdb=# DROP PUBLIC DATABASE LINK public_dblink;
       DROP DATABASE LINK
       gaussdb=# DROP PUBLIC DATABASE LINK public_dblink_to_o;
       DROP DATABASE LINK
       gaussdb=# DROP PUBLIC DATABASE LINK public_dblink_SSL;
       DROP DATABASE LINK
       gaussdb=# RESET ROLE;
       RESET
       gaussdb=# DROP USER local_user;
       DROP ROLE
