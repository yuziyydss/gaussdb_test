1.13.7.35 ALTER SYSTEM SET

功能描述
            在多租数据库特性开启时，在Non-PDB（如postgres库）中使用该命令可完成资源计
            划的切换。
[[PDF_PAGE physical=1272 printed=1223]]
注意事项
       ●    此命令仅限初始用户和拥有sysadmin权限的用户才可使用。
       ●    不支持在PDB内部执行该命令。
       ●    不支持在M兼容数据库中执行该命令。

语法格式
       ALTER SYSTEM SET resource_manager_plan TO plan_name;




参数说明
       plan_name

       资源计划的名称。

示例
       --连接至postgres库，设置当前生效的资源计划为default_resource_plan，新的资源计划实时生效。
       gaussdb=# ALTER SYSTEM SET RESOURCE_MANAGER_PLAN TO 'default_resource_plan';
       ALTER SYSTEM SET
