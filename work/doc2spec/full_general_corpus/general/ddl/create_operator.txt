1.13.9.33 CREATE OPERATOR

功能描述
           创建一个新操作符。


注意事项
           ●   创建操作符的用户将成为其所有者。
           ●   操作符!=在输入时，会被映射成<>，因此操作符!=和操作符<>为等价的操作符。
           ●   对于双目操作符，需要同时定义LEFTARG和RIGHTARG；对右目操作符，仅需要
               定义LEFTARG；对于左目操作符，仅需要定义RIGHTARG。
[[PDF_PAGE physical=1486 printed=1437]]
       ●    仅拥有参数类型以及返回类型的USAGE权限的用户可以创建新的操作符，且必须
            拥有其底层函数的EXECUTE权限。如果指定了交换操作符或者负操作符，当前用
            户还必须拥有这些操作符的USAGE权限。


语法格式
       CREATE OPERATOR name (
          PROCEDURE = function_name
          [, LEFTARG = left_type ] [, RIGHTARG = right_type ]
          [, COMMUTATOR = com_op ] [, NEGATOR = neg_op ]
          [, RESTRICT = res_proc ] [, JOIN = join_proc ]
          [, HASHES ] [, MERGES ]
       );


参数说明
       ●    name
            需要创建的操作符，可以使用模式进行具体指定，如果未指定模式，则在当前模
            式中创建操作符。同一个模式中的两个操作符可以重名，但需要操作不同的数据
            类型。
            命名规范：
            –     操作符的名称是由字符+、-、*、/、<、>、=、~、!、@、#、%、^、&、|、`
                  或?组成的字符串。
            –     --和/*不能在操作符名的任何地方出现，因为其会被作为注释的开始进行使
                  用。
            –     一个多字符的操作符不能以字符+或字符-结尾，除非该操作符名称中至少还
                  包含字符~、!、@、#、%、^、&、|、`或?。
            –     对于=>作为一个操作符名的使用方式已经不再使用，请不要将=>作为操作符
                  名进行定义。
       ●    function_name
            用于实现该操作符的函数。
            对于使用的操作函数（function_name），必须已经通过CREATE FUNCTION进行
            定义，而且必须定义为接受正确数量的指定类型参数（一个或两个）。
       ●    left_type
            对于右目操作符，操作符左边的参数数据类型。对于左目操作符，该参数可以省
            略。
       ●    right_type
            对于左目操作符，操作符右边的参数数据类型。对于右目操作符，该参数可以省
            略。
       ●    com_op
            操作符对应的交换操作符。
       ●    neg_op
            操作符对应的负操作符。
       ●    res_proc
            操作符约束选择性评估函数。
       ●    join_proc
            操作符连接选择性评估函数。
[[PDF_PAGE physical=1487 printed=1438]]
       ●    HASHES
            操作符支持Hash连接。
       ●    MERGES
            操作符支持融合连接。

示例
       --定义一个面积相等，用于box数据类型的新操作符。
       gaussdb=# CREATE FUNCTION area_equal_procedure(box, box)
       RETURNS boolean
       AS $$
       SELECT (area($1) = area($2));
       $$ LANGUAGE sql IMMUTABLE;
       gaussdb=# CREATE OPERATOR === (
          LEFTARG = box,
          RIGHTARG = box,
          PROCEDURE = area_equal_procedure,
          COMMUTATOR = ===,
          NEGATOR = !==,
          HASHES, MERGES
       );
       gaussdb=# SELECT box '(1.0,1.0), (2.0,2.0)' === box'(3,3),(4,4)';
        ?column?
       ----------
        t
       (1 row)
       gaussdb=# DROP OPERATOR ===(box, box);
       DROP OPERATOR

       --在其他Schema下定义操作符。
       gaussdb=# CREATE OPERATOR pg_temp.=== (
          LEFTARG = box,
          RIGHTARG = box,
          PROCEDURE = area_equal_procedure,
          COMMUTATOR = ===,
          NEGATOR = !==,
          HASHES, MERGES
       );
       gaussdb=# SELECT box '(1.0,1.0),(2.0,2.0)' OPERATOR(pg_temp.===) box '(2.0,2.0),(3.0,3.0)';
        ?column?
       ----------
        t
       (1 row)
       gaussdb=# DROP OPERATOR pg_temp.===(box,box);
       DROP OPERATOR
       gaussdb=# DROP FUNCTION area_equal_procedure;
       DROP FUNCTION
