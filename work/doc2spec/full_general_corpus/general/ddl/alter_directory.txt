1.13.7.9 ALTER DIRECTORY

功能描述
            修改一个目录对象的属性。


注意事项
            ●    目前只支持修改目录对象的所有者。
            ●    当enable_access_server_directory=off时，只允许初始用户修改目录对象的所有
                 者；当enable_access_server_directory=on时，具有SYSADMIN权限的用户和目录
                 对象的所有者可以修改目录对象，且要求该用户是新所有者的成员。
            ●    不支持在PDB内使用目录对象。


语法格式
            ALTER DIRECTORY directory_name
              OWNER TO new_owner;




参数说明
            ●    directory_name
                 需要进行修改属性的具体目录。
                 取值范围：已经存在的目录名称。
            ●    new_owner
                 目录的新所有者。


示例
            --创建目录。
            gaussdb=# CREATE OR REPLACE DIRECTORY dir as '/tmp/';

            --创建用户。
            gaussdb=# CREATE USER jim PASSWORD '********';

            --修改目录的owner。
            gaussdb=# ALTER DIRECTORY dir OWNER TO jim;

            --删除目录。
            gaussdb=# DROP DIRECTORY dir;

            --删除用户。
            gaussdb=# DROP USER jim;
