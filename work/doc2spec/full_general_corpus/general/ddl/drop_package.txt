1.13.10.28 DROP PACKAGE

功能描述
           删除已存在的PACKAGE或PACKAGE BODY。

注意事项
           ●    删除PACKAGE BODY后，PACKAGE内的存储过程及函数会同时失效。
           ●    仅初始用户有权对初始用户的PACKAGE进行DROP操作。

语法格式
           DROP PACKAGE [ IF EXISTS ] package_name;




           DROP PACKAGE BODY [ IF EXISTS ] package_name;




参数说明
           ●    IF EXISTS
                判断指定的PACKAGE或PACKAGE BODY是否存在。
                –    如果指定的PACKAGE或PACKAGE BODY存在，则删除成功。
                –    如果指定的PACKAGE或PACKAGE BODY不存在，不会进行删除操作，仅产生
                     一个NOTICE提示，用于告知指定的PACKAGE或PACKAGE BODY不存在。
[[PDF_PAGE physical=1681 printed=1632]]
       ●   package_name
           要删除的PACKAGE名称。
           取值范围：已存在的PACKAGE名。


示例
       --创建PACKAGE。
       gaussdb=# CREATE OR REPLACE PACKAGE PCK1
       IS
       a int;
       END pck1;
       /
       CREATE PACKAGE

       --删除PACKAGE。
       gaussdb=# DROP PACKAGE PCK1;
       DROP PACKAGE


相关链接
       ALTER PACKAGE，CREATE PACKAGE
