1.13.10.26 DROP OPERATOR
           删除一个操作符。

语法格式
           DROP OPERATOR [ IF EXISTS ] name ( { left_type | NONE } , { right_type | NONE } )[ CASCADE |
           RESTRICT ];
[[PDF_PAGE physical=1679 printed=1630]]
参数说明
       ●   name
           需要删除的操作符的名称。
       ●   left_type
           操作符的左操作数的数据类型，如果没有左操作数，则需要指定为NONE。
       ●   right_type
           操作符的右操作数的数据类型，如果没有右操作数，则需要指定为NONE。


示例
       请参见CREATE OPERATOR章节的示例。


相关链接
