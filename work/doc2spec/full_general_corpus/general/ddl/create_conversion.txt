1.13.9.15 CREATE CONVERSION

功能描述
           创建一种新的编码转换规则，用于将数据从一种字符编码（源编码）转换为另一种字
           符编码（目标编码）。

注意事项
           ●    该功能为内部使用功能，用户无法直接使用。仅支持系统内部创建，用户无法直
                接创建。
           ●    参数DEFAULT将在客户端和服务器之间默认执行源编码到目标编码之间的转换。
                要支持这个用法，需要定义双向转换，即从A到B和从B到A之间的转换。
           ●    创建转换需拥有函数的EXECUTE权限及目标模式的CREATE权限。
           ●    源编码和目标编码都不可以使用SQL_ASCII，因为在涉及SQL_ASCII “encoding”
                的情况下，服务器的行为是硬连接的。
           ●    使用DROP CONVERSION可以移除用户自定义的转换规则。

语法格式
           CREATE [ DEFAULT ] CONVERSION name
             FOR 'source_encoding' TO 'dest_encoding' FROM function_name;




参数说明
           ●    DEFAULT
                表示该转换是从源编码到目标编码的默认转换。在一个模式中对于每一个编码
                对，仅有一个默认转换。
           ●    name
                转换规则的名称，可以使用模式进行具体指定。如果没有指定模式，该转换规则
                被定义在当前模式中。在同一个模式中，转换名称必须唯一。
[[PDF_PAGE physical=1412 printed=1363]]
●   source_encoding
    源编码名称。
●   dest_encoding
    目标编码名称。
●   function_name
    被用来执行转换的函数。函数名可以使用模式进行具体指定。如果没有指定模
    式，将在路径中查找该函数。
    该函数必须具有以下格式：
    conv_proc(
       integer, -- 原编码ID
       integer, -- 目标编码ID
       cstring, -- 源字符串（空值终止的C字符串）
       internal, -- 目标（用一个空值终止的C字符串填充）
       integer, -- 源字符串长度
    ) RETURNS void;
