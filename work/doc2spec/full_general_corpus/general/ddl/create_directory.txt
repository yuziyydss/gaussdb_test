1.13.9.18 CREATE DIRECTORY

功能描述
            创建一个目录对象，该目录对象可以定义服务器文件系统上目录的别名，用于存放用
            户使用的数据文件，用户可以通过dbe_file高级包进行读写这些文件。


                须知

            ● 该目录对象对于指定用户可以赋予READ和WRITE的操作权限，用于给dbe_file提供
              权限控制。请合理创建目录对象，如果创建的目录对象在操作系统的关键目录（如
              根目录）下，当对目录文件中的配置进行修改时，可能会造成其他非预期的安全风
              险问题。
            ● 对于用户自行部署的数据库场景，由用户自主完成权限体系的初始配置及管理，当
              进行目录权限授权时，必须确保目标目录满足通过安全基线核查、具备访问控制审
              计机制、以及完成敏感数据分类分级等安全条件要求，并且权限配置应遵循最小权
              限原则，建立权限审批追溯机制等。


注意事项
            ●   当enable_access_server_directory=off时，只允许初始用户创建目录对象。当
                enable_access_server_directory=on时，具有SYSADMIN权限的用户和继承了内置
                角色gs_role_directory_create权限的用户可以创建目录对象。
            ●   创建用户默认拥有此目录对象的READ和WRITE操作权限。
            ●   目录的默认OWNER为创建目录对象的用户。
            ●   以下目录路径禁止创建：
                –    路径含特殊字符。
                –    路径是相对路径。
            ●   创建目录时会进行以下合法性校验：
                –    检查添加路径是否为操作系统实际存在路径，如不存在会提示用户使用风
                     险。
                –    校验数据库初始化（omm）用户对于添加路径的权限（即操作系统目录权
                     限，读/写/执行 - R/W/X），如果权限不足，会提示用户使用风险。
[[PDF_PAGE physical=1428 printed=1379]]
       ●    在数据库环境下用户指定的路径需要用户保证各节点上路径的一致性，否则在不
            同节点上执行会产生无法匹配路径的问题。
       ●    可在pg_directory表中查看已存在目录对象。
       ●    不支持在PDB内使用目录对象。

语法格式
       CREATE [OR REPLACE] DIRECTORY directory_name
       AS 'path_name';




参数说明
       ●    directory_name
            目录名称。
            取值范围：字符串，要符合标识符命名规范。
       ●    path_name
            操作系统的路径。
            取值范围：有效的操作系统路径。

示例
       --创建目录对象。
       gaussdb=# CREATE OR REPLACE DIRECTORY dir AS '/tmp/';

       --查看已创建的目录对象。
       gaussdb=# select * from pg_directory;
        dirname | owner | dirpath | diracl
       ---------+-------+---------+--------
        dir    | 10 | /tmp |
       (1 row)

       --删除目录对象。
       gaussdb=# DROP DIRECTORY dir;
