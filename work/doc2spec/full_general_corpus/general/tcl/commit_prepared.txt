1.13.9.8 COMMIT PREPARED

功能描述
           提交一个早先为两阶段提交准备好的事务。

注意事项
           ●    命令执行者必须是该事务的创建者或系统管理员，且创建和提交操作可以不在同
                一个会话中。
           ●    事务功能由数据库自动维护，不应显式使用事务功能。

语法格式
           COMMIT PREPARED transaction_id [ WITH commit_sequence_number ];




参数说明
           ●    transaction_id
                待提交事务的标识符。
                不能和任何当前预备事务已经使用了的标识符同名。
           ●    commit_sequence_number
                待提交事务的序列号，为一个64位递增的无符号数。

示例
           --开始。
           gaussdb=# BEGIN;

           --创建表。
           gaussdb=# CREATE TABLE item1(id int);

           --准备标识符为trans_test的事务。
           gaussdb=# PREPARE TRANSACTION 'trans_test';
[[PDF_PAGE physical=1376 printed=1327]]
       --查询表item1，这里应该访问不到。
       gaussdb=# SELECT * FROM item1;
       ERROR: Relation "item1" does not exist on test.
       LINE 1: SELECT * FROM item1;

       --提交标识符为trans_test的事务。
       gaussdb=# COMMIT PREPARED 'trans_test';

       --查询表item1，这里应该可以访问。
       gaussdb=# SELECT * FROM item1;
        a
       ---
       (0 rows)
       --删除表。
       gaussdb=# DROP TABLE item1;
