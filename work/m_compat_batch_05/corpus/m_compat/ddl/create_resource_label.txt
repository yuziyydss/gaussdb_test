2.4.2.8.12 CREATE RESOURCE LABEL

功能描述
             用于创建资源标签。

注意事项
             仅POLADMIN、SYSADMIN或初始用户能可以执行CREATE RESOURCE LABEL命令。

语法格式
             CREATE RESOURCE LABEL [IF NOT EXISTS] label_name ADD label_item_list [, ...];
[[PDF_PAGE physical=2109 printed=2060]]
       ●    label_item_list：需要标记的数据库资源的类型，具体形式为：
            resource_type (resource_path [, ...])




       ●    resource_type：描述具体的数据库资源的路径，具体形式为：
            { TABLE | COLUMN | SCHEMA | VIEW | FUNCTION }




参数说明
       ●    IF NOT EXISTS
            判断指定的资源标签是否存在，使用该参数可以避免出现报错。
            –     如果指定的资源标签不存在，直接进行CREATE操作。
            –     如果指定的资源标签存在，则产生NOTICE，不会抛出错误。
       ●    label_name
            资源标签名称，必须确保其唯一性，不可重复。
            取值范围：字符串，要符合标识符说明。
            命名规则：
            –     资源标签名必须由小写字母（a~z）、大写字母（A~Z）、下划线（_）、数
                  字（0~9）或美元符号（$）组成，且必须以字母或下划线开头。
            –     资源标签名称的最大长度不超过63个字符。若超过63个字符，数据库会截断
                  并保留前63个字符当作资源标签名称。
            –     当资源标签名称中包含大写字母时数据库会自动转换为小写字母，如果需要
                  创建包含大写字母的资源标签名称则需要使用反引号括起来。
       ●    resource_type
            需要标记的数据库资源的类型。
            取值范围：表（TABLE）、列（COLUMN）、模式（Schema）、视图（VIEW）
            以及函数（FUNCTION）。
       ●    resource_path
            描述具体的数据库资源的路径。

示例
       -- 创建数据表tb_for_label。
       m_db=# CREATE TABLE tb_for_label(col1 text, col2 text, col3 text);
[[PDF_PAGE physical=2110 printed=2061]]
       -- 基于表创建资源标签。
       m_db=# CREATE RESOURCE LABEL IF NOT EXISTS table_label add TABLE(public.tb_for_label);

       -- 再次创建已存在的表资源标签，对比加参数IF NOT EXISTS与不加IF NOT EXISTS参数的区别。
       m_db=# CREATE RESOURCE LABEL IF NOT EXISTS table_label add TABLE(public.tb_for_label);
       NOTICE: table_label label already defined, skipping
       CREATE RESOURCE LABEL
       m_db=# CREATE RESOURCE LABEL table_label add TABLE(public.tb_for_label);
       ERROR: table_label label already defined

       -- 基于列创建资源标签。
       m_db=# CREATE RESOURCE LABEL IF NOT EXISTS column_label add COLUMN(public.tb_for_label.col1);

       -- 创建模式schema_for_label。
       m_db=# CREATE SCHEMA schema_for_label;

       -- 基于模式创建资源标签。
       m_db=# CREATE RESOURCE LABEL IF NOT EXISTS schema_label add SCHEMA(schema_for_label);

       -- 创建视图view_for_label。
       m_db=# CREATE VIEW view_for_label AS SELECT 1;

       -- 基于视图创建资源标签。
       m_db=# CREATE RESOURCE LABEL IF NOT EXISTS view_label add VIEW(view_for_label);

       -- 删除表资源标签table_label。
       m_db=# DROP RESOURCE LABEL IF EXISTS table_label;

       -- 删除列资源资源标签column_label。
       m_db=# DROP RESOURCE LABEL IF EXISTS column_label;

       -- 删除视图资源标签view_for_label。
       m_db=# DROP VIEW view_for_label;

       -- 删除模式资源标签schema_for_label。
       m_db=# DROP SCHEMA schema_for_label;

       -- 删除表tb_for_label。
       m_db=# DROP TABLE tb_for_label;
