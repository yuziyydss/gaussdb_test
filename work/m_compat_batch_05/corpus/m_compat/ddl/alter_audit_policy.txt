2.4.2.6.1 ALTER AUDIT POLICY

功能描述
             修改统一审计策略。

注意事项
             ●   审计策略的维护存在权限限制，仅POLADMIN，SYSADMIN或初始用户可以执行
                 ALTER AUDIT POLICY命令。
             ●   仅在打开enable_security_policy开关后，统一审计策略才可生效。

语法格式
             ●   添加或删除审计策略中的操作类型
                 ALTER AUDIT POLICY [ IF EXISTS ] policy_name { ADD | REMOVE } { [ privilege_audit_clause ]
                 [ access_audit_clause ] };




                 –    privilege_audit_clause：表示审计策略中具体的DDL操作类型及目标资源标
                      签，具体形式为：
                      PRIVILEGES ({ PRIVILEGES | ALL } [ ON LABEL ( resource_label_name [, ... ] ) ])




                 –    access_audit_clause：表示审计策略中具体的DML操作类型及目标资源标
                      签，具体形式为：
                      ACCESS ({ ACCESS | ALL } [ ON LABEL ( resource_label_name [, ... ] ) ])




                 –    PRIVILEGES：表示针对数据库执行以下操作时进行审计，具体包括：
                      { ( ALTER | ANALYZE | COMMENT | CREATE | DROP | GRANT | REVOKE | SET | SHOW ) }
                 –    ACCESS：表示针对数据库执行以下操作时进行审计，具体包括：
                      { ( COPY | DEALLOCATE | DELETE | EXECUTE | REINDEX | INSERT | PREPARE | SELECT |
                      TRUNCATE | UPDATE ) }

             ●   修改审计策略中的过滤条件
                 ALTER AUDIT POLICY [ IF EXISTS ] policy_name MODIFY ( filter_group_clause );
[[PDF_PAGE physical=2013 printed=1964]]
           filter_group_clause：表示审计策略中的过滤条件，具体形式为：
           FILTER ON { filter_type ( filter_value [, ... ] ) } [, ... ]




       ●   删除审计策略中的过滤条件
           ALTER AUDIT POLICY [ IF EXISTS ] policy_name DROP FILTER;




       ●   修改审计策略描述
           ALTER AUDIT POLICY [ IF EXISTS ] policy_name COMMENTS policy_comments;




       ●   打开或者关闭审计策略
           ALTER AUDIT POLICY [ IF EXISTS ] policy_name { ENABLE | DISABLE };




参数说明
       ●   policy_name
           指定审计策略的名称，必须确保其唯一性，不可重复。
           取值范围：字符串，要符合标识符说明。
       ●   resource_label_name
           资源标签名称。
       ●   PRIVILEGES
           表示针对数据库执行以下操作时进行审计，目前支持对数据库进行CREATE、
           ALTER、DROP、ANALYZE、COMMENT、GRANT、REVOKE、SET以及SHOW操
           作时的审计。
       ●   ACCESS
           表示针对数据库执行以下操作时进行审计，目前支持对数据库进行SELECT、
           COPY、DEALLOCATE、DELETE、EXECUTE、INSERT、PREPARE、REINDEX、
           TRUNCATE以及UPDATE操作时的审计。
       ●   { PRIVILEGES | ALL } | { ACCESS | ALL }
           表示在PRIVILEGES或ACCESS中，支持的所有对数据库的操作。
           –     { PRIVILEGES | ALL }：ALL指所有PRIVILEGES操作；
           –     { ACCESS | ALL }：ALL指所有ACCESS操作。
       ●   filter_type
           审计策略过滤的条件类型。过滤类型包括IP、ROLES以及APP。
       ●   filter_value
           具体过滤信息内容。
       ●   policy_comments
           用于记录策略相关的描述信息。
[[PDF_PAGE physical=2014 printed=1965]]
       ●   ENABLE | DISABLE
           打开或关闭统一审计策略。

示例
       ●   添加或删除审计策略中的操作类型
           -- 创建一个对数据库执行CREATE的审计策略adt1。
           m_db=# CREATE AUDIT POLICY adt1 PRIVILEGES CREATE;

           -- 添加adt1审计策略中的DROP。
           m_db=# ALTER AUDIT POLICY adt1 ADD PRIVILEGES (DROP);

           -- 删除adt1审计策略中的DROP。
           m_db=# ALTER AUDIT POLICY adt1 REMOVE PRIVILEGES (DROP);

       ●   修改审计策略的注释信息
           -- 修改adt1审计策略的注释信息为adt1_comments。
           m_db=# ALTER AUDIT POLICY adt1 COMMENTS 'adt1_comments';

       ●   修改审计策略的过滤信息
           -- 创建bob_audit用户。
           m_db=# CREATE USER bob_audit PASSWORD '********';

           -- 修改adt1审计策略的过滤用户为bob_audit。
           m_db=# ALTER AUDIT POLICY adt1 MODIFY (FILTER ON (ROLES(bob_audit)));

           -- 删除bob_audit用户。
           m_db=# DROP USER bob_audit;

       ●   删除审计策略的过滤条件
           -- 删除adt1审计策略的过滤条件。
           m_db=# ALTER AUDIT POLICY adt1 DROP FILTER;

       ●   关闭审计策略
           -- 关闭adt1审计策略。
           m_db=# ALTER AUDIT POLICY adt1 DISABLE;

           -- 删除adt1审计策略。
           m_db=# DROP AUDIT POLICY adt1;
