2.4.2.8.14 CREATE SCHEMA

功能描述
             M-Compatibility中DATABASE与SCHEMA是同义词。该语法表示创建模式
             访问命名对象时可以使用模式名作为前缀进行访问，如果无模式名前缀，则访问当前
             模式下的命名对象。创建命名对象时也可用模式名作为前缀修饰。

注意事项
             ●   只要用户对当前数据库有CREATE权限，就可以创建模式。
             ●   系统管理员在普通用户同名模式Schema下创建的对象，所有者为模式Schema的
                 同名用户（非系统管理员）。

语法格式
             CREATE {DATABASE | SCHEMA} [IF NOT EXISTS] schema_name
                [[create_option] [,...]]
             create_option: [DEFAULT] {
                CHARACTER SET [=] default_charset
              | CHAR SET [=] default_charset
              | CHARSET [=] default_charset
[[PDF_PAGE physical=2115 printed=2066]]
           | COLLATE [=] default_collation
       }



参数说明
       ●       schema_name
               模式名称。
               取值范围：字符串，要符合标识符说明。

                说明

              ● 模式名不能和当前数据库里其他的模式重名。
              ● 模式名不能和当前数据库的初始用户重名。
              ● 模式的名称不可以“pg_”开头。
              ● 模式的名称不可以“gs_role_”开头。
              ● 如果当前搜索路径上的模式中存在同名对象时，需要明确指定引用对象所在的模式。可以通
                过命令SHOW SEARCH_PATH来查看当前搜索路径上的模式。

       ●       COLLATE [=] collation_name
               可选。指定新数据库（模式）使用的字符集。例如，通过collate = 'zh_CN.gbk'设
               定该参数。
               该参数的使用会影响到对字符串的排序顺序（如使用ORDER BY执行，以及在文本
               列上使用索引的顺序）。默认是使用模板数据库的字符集。
               取值范围：请参见库级字符集和字符序。
       ●       {CHAR SET | CHARSET | CHARACTER SET} [=] charset_name
               可选。指定新数据库（模式）使用的字符分类。例如，通过CHARSET =
               'zh_CN.gbk'设定该参数。该参数的使用会影响到字符的分类，如大写、小写和数
               字。默认是使用模板数据库的字符分类。
               取值范围：请参见库级字符集和字符序。


示例
       --创建并切换至测试数据库。
       m_db=# CREATE SCHEMA test1;
       m_db=# USE test1;
       --创建表a。
       m_db=# CREATE TABLE a(id int);
       m_db=# DROP TABLE a;
       --删除SCHEMA test1。
       m_db=# USE public;
       m_db=# DROP SCHEMA test1;
