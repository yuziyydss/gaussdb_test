8.2.2.1 GS_ABNORMAL_SQL_INFO
              GS_ABNORMAL_SQL_INFO系统表提供了数据库CPU使用异常的SQL的信息，数据来
              源于DBE_PERF.ABNORMAL_SQL视图，每10s系统表从视图同步一次。

               is_logged_when_con        boolean        被管控时是否打印日志。

8.2.2.2 GS_ABNORMAL_SQL_WHITE_LIST

               名称                        类型             描述

8.2.3 OLTP 表压缩

8.2.3.1 GS_ILM
              GS_ILM系统表提供了ILM策略的主体信息，其中包括策略名称、策略属主、策略类
              型、策略编号和策略状态。

              表 8-6 GS_ILM 字段
                 名称        类型             描述

                 pidx      integer        策略序号，全局唯一以1开始的流水号。

                 creator   oid            策略属主。

                 name      name           策略名称，目前不支持自定义名称，默认名称为p
                                          +pidx。

                 ptype     "char"         策略类型：
                                          ● m：DATA MOVEMENT。

                 flag      smallint       取值范围：
                                          ● 0：策略整体启用状态。
                                          ● 1：策略整体被禁用。
                                          ● 2：库级策略。
