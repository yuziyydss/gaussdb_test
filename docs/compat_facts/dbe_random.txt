              ●   DBE_RANDOM.GET_VALUE
                  函数GET_VALUE生成一个大小介于指定的low及high之间的随机数。
                  DBE_RANDOM.GET_VALUE原型为：
                  DBE_RANDOM.GET_VALUE(
                  min IN NUMBER default 0,
                  max IN NUMBER default 1)
                  RETURN NUMBER;


                  表 3-268 DBE_RANDOM.GET_VALUE 接口参数说明
                   参数           描述

                   min          指定随机数大小的下边界，生成的随机数大于或等于min。

                   max          指定随机数大小的上边界，生成的随机数小于max。




                         说明

                       ● DBE_RANDOM.GET_VALUE要求参数类型是NUMERIC，对于左右边界的大小并没有要
                         求。
                       ● DBE_RANDOM实现的是伪随机，所以若使用的初值（种子）不变，那么伪随机数的数
                         序也不变，使用时需要注意，建议不要在安全场景下使用DBE_RANDOM。
                       ● 生成的随机数有效数字为15位。
                  示例：
                  -- 产生0到1之间的随机数。
                  SELECT DBE_RANDOM.GET_VALUE(0,1);
                     get_value
                  ------------------
                   .917468812743886
                  (1 row)

                  -- 对于指定范围内的整数，要加入参数min和max，并从结果中截取较小的数（最大值不能被作为可能的
                  值）。所以对于0到99之间的整数，使用下面的代码。
                  SELECT TRUNC(DBE_RANDOM.GET_VALUE(0,100));

3.12.2.16 DBE_RAW
              DBE_RAW包提供了用于操作RAW类型的接口。

                  说明

                 RAW类型的外部表现形式是十六进制，内部存储形式是二进制。例如一个RAW类型的数据
                 11001011的表现形式为‘CB’，即在实际的类型转换中输入的是‘CB’。


权限介绍
              DBE_RAW模式属于系统目录，DBE_RAW模式除了系统管理员用户在初始化数据库时
              拥有创建权限，模式及模式下的所有接口，所有用户仅具有使用权限。


接口介绍

                  表 3-270 DBE_RAW.CAST_FROM_BINARY_INTEGER_TO_RAW 接口参数说明

                   参数          描述

                   value       待转成RAW类型的INTEGER类型值。
                               说明
                                DBE_RAW.CAST_FROM_BINARY_INTEGER_TO_RAW预期处理INTEGER类
                                型值，为了兼容性考虑，该参数被定义为BIGINT类型，BIGINT类型范围比

                   endianess   字节序，取值范围：整型值1、2或3。

                               ● 2表示LITTLE_ENDIAN。

                               如果机器默认为BIG_ENDIAN，则函数执行结果
                               MACHINE_ENDIAN和BIG_ENDIAN一致，如果机器默认为
                               LITTLE_ENDIAN，则函数执行结果MACHINE_ENDIAN和
                               LITTLE_ENDIAN一致。
