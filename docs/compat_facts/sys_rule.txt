8.2.17 基于 DSL 的规则引擎

8.2.17.1 GS_DSL_REWRITERULE
              GS_DSL_REWRITERULE系统表记录DSL规则的信息，初始用户才可以修改此表。


              表 8-73 GS_DSL_REWRITERULE 字段

               名称               类型          描述

               rulename         name        规则name，全局唯一，由用户增加规则时输入填
                                            充。字母开头，不支持中文；支持字母、数字、下
                                            划线、中划线组合；不支持其他特殊字；长度不超
                                            过64个字节。

               ruledesc         name        规则实现功能的简要描述，长度不超过64个字
                                            节。

               enabled          boolean     是否启用此规则。

               externalrule     boolean     是否为外置规则，外置规则为TRUE，内置规则为
                                            FALSE。

               costbased        boolean     是否基于代价启用该规则，该功能当前不支持。

               priority         integer     优先级，全局唯一，支持范围1-9999，数字越大
                                            优先级越低。

               dbcompatibilit   tinyint     此字段使用bit位映射的方式存储RULE的数据库兼
               y                            容模式，具体bit位标识转为十进制后如下：
                                            ● 01：标识A兼容，表示O数据库兼容。
                                            ● 02：标识B兼容，表示MY数据库兼容。
                                            ● 04：标识C兼容，表示TD数据库兼容。
                                            ● 08：标识PG兼容，表示POSTGRES数据库兼
                                              容。
                                            ● 16：标识M兼容，表示M-Compatibility兼容。
                                            ● 31：标识所有数据库兼容。

8.2.18 HTAP

8.2.18.1 GS_IMCV
              GS_IMCV系统表提供了所有IMCV表的元信息。

              表 8-74 GS_IMCV 字段

               名称                      类型                      描述

               reloid                  oid                     表id。

               relname                 name                    表名。

               dbname                  name                    数据库名。

               username                name                    IMCV表的owner。

               parentoid               oid                     父表id。如果是分区，则表
                                                               示父表id，否则显示0。

               imcvispart              boolean                 是否是分区表。
