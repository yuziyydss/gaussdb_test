8.2.12.1 GS_MASKING_POLICY
              GS_MASKING_POLICY系统表记录动态数据脱敏策略的主体信息，每条记录对应一个
              脱敏策略。需要有系统管理员或安全策略管理员权限才可以访问此系统表。

              表 8-49 GS_MASKING_POLICY 表字段

               名称                     类型                  描述

                                                          择）。

               polname                name                策略名称，唯一不可重复。

               polcomments            name                策略描述字段，记录策略相关的描述
                                                          信息，通过COMMENTS关键字体
                                                          现。

               modifydate             timestamp without   策略创建或修改的最新时间戳。
                                      time zone

               polenabled             boolean             策略启动开关。
                                                          ● t（true）：表示策略启动。
                                                          ● f（false）：表示策略没有启动。

8.2.13 DATABASE LINK

8.2.13.1 GS_DATABASE_LINK
              GS_DATABASE_LINK系统表是用于存储DATABASE LINK信息的系统表，主要记录的是
              DATABASE LINK对象的详细信息。只有具备SYSADMIN权限的用户才可以对该系统表
              进行读操作。

              表 8-52 GS_DATABASE_LINK 字段

               名称           类型              描述

               oid          oid             当前DATABASE LINK对象的唯一id（隐含属性，必须
                                            明确选择）。

               dlname       name            当前DATABASE LINK的名称。

               dlowner      oid             当前DATABASE LINK的拥有者id，显示public则为
                                            0。

               dlfdw        oid             当前DATABASE LINK的外部数据封装器的OID。

               dlcreater    oid             当前DATABASE LINK创建者的id。

               options      text[]          当前DATABASE LINK连接信息，使用
                                            "keyword=value"。

               useroption   text[]          当前DATABASE LINK连接远端所使用的用户信息，使
               s                            用"keyword=value"。

               dlacl        aclitem[]       当前DATABASE LINK访问权限。

8.2.14.1 GS_MATVIEW
              GS_MATVIEW系统表提供了关于数据库中每一个物化视图的信息。

               名称                 类型             描述

               oid                oid            行标识符（隐含属性，必须明确选择）。

               matviewid          oid            物化视图的oid。

                                                 表，与物化视图一一对应。全量物化视图不存在

                                                 化视图。
