## 本轮实质改进

1. 实际SQL目标身份检查独立于赋值表达式：视图冲突写入、INSERT IGNORE、外层CTE与ON DUPLICATE、多表视图UPDATE、元组子查询排序/限行、内联主键更新限制。M与未知来源不借用一般模式规则。
2. 查询列数/类型列表不再因zip截短漏检；递归DML CTE保留外层来源模式。M REPLACE SET按受控默认新输入、从左到右处理有限整数赋值，不读取旧种子行代替新行。
3. ADD/RENAME/MODIFY复用实际DDL和有限字面量种子检查；MODIFY扩长与NOT NULL必须满足真实前置条件。索引可见性增加两个受严格环境门约束的代表，不扩大为全域支持。
4. INSERT文档中的query/subquery指代歧义不再作为已确认硬禁令。原负例移入不可执行planned审阅场景；生成发布和独立库存检查保护历史SQL，未登记多余文件会失败。
5. 回归输入指纹增加归档规格；失败记录不覆盖。全量发现旧测试与已确认新规则冲突后，仅对齐测试并加强M/未知来源同基表待审断言，没有改生产SQL或负例预期。
